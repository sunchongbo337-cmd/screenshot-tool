图 3-1 系统硬件拓扑图（3.1.1 硬件拓扑设计）

本系统为单机部署架构：用户 PC 通过显示接口连接 1～N 块显示器，输入设备（键鼠）触发截图热键； 认证服务以进程形式监听本机 127.0.0.1:4177，数据存储于本地磁盘，截图画面不经过网络传输。

  subgraph UserSite["用户侧（办公室/个人 PC）"]
    KB["键盘\nAlt+A / Alt+Shift+A"]
    MS["鼠标\n区域框选"]
    subgraph PC["用户主机 PC\nWindows 10/11 x64\nCPU≥双核 RAM≥4GB"]
      GPU["显卡/GPU\n帧缓冲"]
      CPU["CPU\nElectron+Chrome进程"]
      DISK["本地磁盘\n截图保存/auth.json"]
      subgraph Processes["运行进程"]
        DESK["ScreenShot.exe\nElectron 桌面端"]
        BR["Chrome/Edge 浏览器\n+ 扩展 content.js"]

      end
    end

      MON2["扩展显示器\n可选"]
    end
  end

图 3-4 分层渲染模型（3.3.4.1）

Konva Stage 渲染顺序自下而上：背景 → 马赛克 → 标注 → 裁剪框。 裁剪框交互时 zIndex=999 强制置顶，确保拖动时不被其他元素遮挡。 

flowchart TB
  subgraph Stage["Konva Stage 渲染顺序（自下而上）"]
    L1["① 背景图片 Group\n截图底图 | 不可交互"]
    L2["② 马赛克层\nmosaicRect + mosaicStroke\n按 updatedAt 排序 | 可选中/拖动/删除"]
    L3["③ 标注层\n箭头 + 文字\nlayer='top' | 可编辑/拖动/修改样式"]
    L4["④ 裁剪框 Group\nCropSelection + 8 handles\nzIndex=999 | 交互时强制置顶"]
  end

  L1 --> L2 --> L3 --> L4

  style Stage fill:#f3e5f5,stroke:#7b1fa2
